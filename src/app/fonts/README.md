# Bundled fonts

The root layout uses `next/font/local` so builds do not need Google Fonts access.
Both variable fonts preserve the original families, normal style and weights
100–900, including Arabic and Latin glyphs in Noto Kufi Arabic.

Source: https://github.com/google/fonts/tree/9710da1eacb3be272583c3224dcb70f9da6eadbb/ofl

- `notokufiarabic/NotoKufiArabic[wght].ttf`
- `geistmono/GeistMono[wght].ttf`

Original files were retrieved over verified HTTPS and compressed without
subsetting using FontTools 4.61.1 and Brotli 1.1.0. Glyph maps and variable weight
axes were checked after loading the WOFF2 outputs. The fonts are licensed under
SIL OFL 1.1; each original license is bundled here.
